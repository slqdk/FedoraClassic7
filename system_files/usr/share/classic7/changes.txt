# Classic 7 changes, newest first. Shown by Classic 7 Update (View update history) and in the
# "Classic 7 was updated" message after a restart. Format: "## YYYY-MM-DD  Title", then "- item".

## 2026-10-13  Aero, Personalization, Taskbar and Start Menu Properties
- **The Aero look**, as well as Classic: glass window borders and a glass taskbar in the colour you choose, the round Start button, a Start menu with a white list and the glass column on the right, task buttons with icons where programs are pinned, Aero Peek on the Show desktop button, Windows 7 buttons, tabs and scroll bars in programs, a new wallpaper and white cursors. **Basic** is the same look in light blue without glass. New accounts start in Aero; your account keeps Classic until you choose otherwise.
- **Personalization** (Control Panel > Appearance and Personalization > Personalization): click Aero, Basic or Classic and Apply. **Window Color** has 16 glass colours, Enable transparency, Color intensity and a colour mixer, with a preview; the Classic colour schemes and the font size are on the Appearance tab. Programs that are open get the new controls when they start again.
- **Taskbar and Start Menu Properties** (right-click the taskbar > Properties, or right-click the Start button > Properties): Lock the taskbar, Auto-hide, Use small icons, the taskbar's place on the screen, how task buttons combine, which notification area icons show (Customize...), Aero Peek; the Start menu's links and number of recent programs (Customize...), what the power button does, and Quick Launch under Toolbars. *Lock the taskbar* is also on the taskbar's right-click menu.
- **Pin to Taskbar** pins to the task buttons in Aero and Basic (to Quick Launch in Classic).
- Control Panel has **Taskbar and Start Menu**, and **Notification Area Icons** opens the Windows 7 window for the tray icons.

## 2026-10-13  Remote Desktop both ways, Control Panel in Small icons, fewer startup programs
- **Remote Desktop to this computer works again.** Windows said "Your credentials did not work" for every account, because KDE's Remote Desktop server and the newer FreeRDP that Fedora updated to didn't agree on how to log on. Classic 7 now carries KDE's fix until Plasma ships it.
- **System Properties > Remote** (Control Panel > System > Remote settings): choose *Allow connections from computers running any version of Remote Desktop* and click OK. Log on from Windows with this computer's account name and password while you are logged on here; nothing has to be accepted on this screen, the certificate lasts ten years, and Classic 7 offers to open the firewall. Select Users... adds names and passwords only for Remote Desktop.
- **Remote Desktop Connection** to Windows computers (Start > All Programs > Accessories, or `mstsc` in Run): the Windows 7 window with Show Options (General, Display, Local Resources, Experience, Advanced), the Windows Security box for the user name and password (Remember my credentials), and .rdp files that open with a double-click and that Windows can open too.
- **Control Panel** opens in **Small icons**, and keeps the view you choose under *View by* (Category, Large icons or Small icons).
- **Fewer startup programs**: Bazzite Announcements and KDE Connect no longer start at login (tick them in System Configuration > Startup to have them back), and the XApp tray helper, which Plasma doesn't need, is gone. System Configuration lists only what really starts; the desktop's own helpers are behind *Hide the desktop's own startup items*.
- **Command Prompt** opens without Bazzite's "Welcome to Bazzite" banner (Konsole too).

## 2026-10-13  Accessories, Explorer windows, notification area, system tools, screen savers, start-up and shut-down screens
- **Accessories** in the Windows 7 look, in their own Start > All Programs > **Accessories** folder (with **System Tools** inside, as in Windows 7): Notepad, Calculator (Standard, Scientific and Programmer, History), Paint, Sticky Notes, and Character Map under System Tools.
- **Quick Shot** instead of the Snipping Tool, like Lightshot: press **Ctrl+Up** (or PrtSc), drag over the part of the screen you want, draw on it (pen, line, arrow, rectangle, marker, text), then Copy, Save, Print, E-mail or Open in Paint. Shift+PrtSc saves the whole screen.
- **Recycle Bin** window like Windows 7 (double-click the desktop icon): where each file came from and when it was deleted, Restore this item / Restore all items, Empty the Recycle Bin. The desktop icon shows full or empty whoever deletes or empties.
- **Properties** like Windows 7 for files, folders, shortcuts and drives (right-click > Properties or Alt+Enter): General with sizes and attributes, Security, Details, Customize (folder icon), Shortcut, and Tools (Check now) for drives.
- **Copying, moving and deleting** shows the Windows 7 progress window: "Copying 1,250 items from Downloads to Documents", time remaining, More details with speed and items left, Cancel. Quick operations show nothing, as in Windows.
- **Notification area**: the clock opens a calendar with a clock face (Change date and time settings... opens **Date and Time** with time zone and Internet Time); the speaker opens a volume slider with Mute and **Mixer** (**Volume Mixer**: one slider per program playing sound); the **Action Center** flag lists problems (firewall off, updates, nearly full drives, programs that stopped working) and opens Action Center.
- **System Configuration** (`msconfig` in Run): turn startup programs and services on or off, see the Classic 7 versions the computer can start. **Event Viewer** (`eventvwr`): the system's log by Application, Security, Setup and System, with levels, sources, filters and Problem Reports.
- **Resource Monitor** (`resmon`, or Task Manager > Performance > Resource Monitor): CPU, memory, disk and network per program with graphs. **Firewall** (Control Panel > System and Security, or `firewall.cpl`): turn the firewall on or off for home/work and public networks, allow programs through, restore defaults.
- **Screen savers**: Mystify, 3D Pipes, Bubbles, Ribbons, 3D Text, Photos and Blank. Mystify starts after 4 minutes without mouse or keyboard; choose another one, the time, or (None) in **Screen Saver Settings** (Control Panel > Appearance and Personalization > Screen Saver). Films and games that keep the screen on, and full-screen windows, hold the screen saver off.
- **Start-up and shut-down**: "Starting Classic 7" with four coloured lights while the computer starts, and Log off, Restart and Shut down in the Start menu show the classic "Logging off..." / "Restarting..." / "Shutting down..." screen until the computer is off.

## 2026-10-13  Taskbar menu, Programs and Features, one network icon
- **Right-click the taskbar** for the Windows 7 menu: Cascade windows, Show windows stacked, Show windows side by side, Show the desktop and **Start Task Manager**.
- **Programs and Features** (Control Panel > Uninstall a program, or `appwiz.cpl` in Run): app store apps, Steam games and packages added to the system, with publisher, install date, size and version. Select one and click Uninstall (Steam games are removed by Steam itself; added packages after a restart). Get new programs opens the app store.
- The Control Panel's "Uninstall a program" and "Install a program" links work again (the app store is a normal program on Bazzite, not a Flatpak).
- Only one network icon in the notification area also with Plasma 6.7, which keeps the icons inside the tray itself.

## 2026-10-13  Sheet (spreadsheets), Disk Management, Control Panel, Task Manager, Ctrl+Alt+Del, System and Device Manager, Windows 7 taskbar keys
- **Sheet**, a spreadsheet in the Excel 2007 style (Start menu, `excel` in Run): opens .xlsx and old .xls workbooks and CSV files, saves .xlsx, CSV and PDF. About 200 functions (SUM, IF, VLOOKUP, INDEX/MATCH, SUMIFS, dates, text, finance), number formats, Format Cells, borders, merge, Conditional Formatting, Data Validation, sort and AutoFilter, Freeze Panes, charts (column, bar, line, pie, area, scatter), comments, names, find and replace, and printing with Page Setup.
- **Disk Management** (`diskmgmt.msc` in Run, Control Panel > System and Security, or Computer > Manage drives): the volume list and the disks drawn as bars. Right-click a volume: **Change Drive Letter and Paths**, Format, Delete Volume, Check for Errors, Use for Steam Games; right-click unallocated space: New Simple Volume; new disks: Initialize Disk (GPT or MBR). An administrator password is asked for changes.
- **Drive letters**: a drive with a letter is opened at every start-up at /var/mnt/<letter> (an entry in /etc/fstab), so Steam libraries on extra drives are always there. The Computer window shows the letters: Local Disk (C:), Games (D:).
- **Steam on NTFS/exFAT drives**: Use for Steam Games makes a SteamLibrary folder and keeps Proton's Windows folders (compatdata) on the system disk, so Windows games start from NTFS drives too. Disk Management explains this when you give an NTFS drive a letter.
- **Control Panel** like Windows 7 (Start > Control Panel, `control` in Run): Category view with the eight categories, category pages, All Control Panel Items (large or small icons) and search. Items open the matching settings window by itself; `control mouse`, `main.cpl`, `desk.cpl`, `mmsys.cpl`, `timedate.cpl` and friends work in Run.
- **Task Manager** (Ctrl+Shift+Esc, `taskmgr`): Applications (switch to or end a window), Processes (CPU, memory, description; end process or process tree, priority, affinity), Services (start/stop), Performance (CPU and memory meters and history, one graph per CPU), Networking and Users; Shut Down menu.
- **Ctrl+Alt+Del** shows the blue Windows 7 screen: Lock this computer, Switch User, Log off, Change a password..., Start Task Manager, Cancel; Ease of Access and the red power button with Sleep/Restart/Shut down.
- **System** (Win+Pause, Computer > System properties): processor, memory, graphics, computer name and workgroup. **System Properties** (`sysdm.cpl`): rename the computer, environment variables, System Restore (go back to the previous Classic 7 version), Remote Desktop. **Device Manager** (`devmgmt.msc`): every device by type with its driver and status; devices without a driver get the yellow sign.
- **Taskbar and windows**: the narrow **Show desktop** button at the right end of the taskbar; **Alt+Tab** like Windows 7 Classic (a grey box of icons with the window title); **Aero Shake** (shake a window by its title bar to minimize the others, shake again to bring them back; also Win+Home); **Win+Up** maximizes, **Win+Down** restores or minimizes, Win+Left/Right snap to half the screen, dragging a window to the top edge maximizes it.
- **Jump lists** in the Start menu: rest the mouse on Write or Show to see your recent documents on the right; Mail, Steam, Firefox and others have tasks (New e-mail message, Library, Store, New private window...).

## 2026-10-13  Classic 7 Update: check first, then install
- **Check for updates** only checks: nothing is downloaded until you click **Install updates**. When a new Classic 7 is available, the window lists what's new in it first.
- Installing shows real progress while the new version downloads (GB downloaded and percent).
- **Restore Classic 7 settings** asks before it re-applies the look, taskbar and shortcuts.

## 2026-10-12  Show (PowerPoint), Photo Viewer, 7-Zip
- **Show**, presentations in the PowerPoint 2007 style (Start menu, or `powerpnt` in Run): Office button, ribbon (Home, Insert, Design, Animations, Slide Show, Review, View, and Format/Table tabs when something is selected), the Slides and Outline pane, notes, Slide Sorter, zoom.
- Slides with the nine standard layouts and nine designs (themes) with colour and font sets and background styles; text with fonts, sizes, colours, bullets and numbering in levels (Tab/Shift+Tab), alignment; shapes (lines, arrows, rectangles, stars, callouts, flowchart...) with fill, outline and quick styles; pictures, tables (header row, banded rows, merge, insert rows/columns), text boxes, hyperlinks, header and footer, slide numbers; move, size, rotate, flip, group, align, order; undo/redo, copy/paste, Find and Replace, spelling.
- Slide show (F5) with transitions (fade, push, wipe, split, cover, zoom, circle, dissolve...), entrance animations (appear, fade, wipe, fly in, zoom), automatic timings, loop, pen, black/white screen, Go to Slide.
- Opens PowerPoint 2007-2019 files (.pptx .ppsx .potx .pptm) and old PowerPoint 97-2003 files (.ppt .pps); saves .pptx and .ppsx (and PDF and pictures). Old .ppt files are saved as .pptx. Prints slides, handouts and notes pages; Send by e-mail. Right-click a presentation > Show plays it.
- **Photo Viewer** like Windows 7's (double-click a picture, or `photoviewer` in Run): Left/Right arrows (or the buttons) go to the previous/next picture in the folder, mouse wheel zooms, drag to move, 1:1 / fit to window, rotate left/right (Ctrl+, / Ctrl+.) and flip horizontally/vertically. Turns are saved when you go to the next picture (JPEG without losing quality). Slide show (F11) with fade, Delete to the Recycle Bin, Rename (F2), Copy, Print, E-mail (pick the size), Open with, Set as desktop background, Properties with camera details.
- Opens JPEG, PNG, GIF (animated too), BMP, TIFF, WebP, ICO, SVG, HEIC, AVIF, JPEG XL, camera RAW, PSD and more. Pictures now open in Photo Viewer by default.
- **7-Zip** is included: right-click files > 7-Zip > Add to archive... / Add to .7z / Add to .zip, and archives > 7-Zip > Open archive / Extract files... / Extract Here / Extract to own folder. 7z, zip, rar, tar, gz, xz, iso and more open in the 7-Zip File Manager (Start menu); `7z` works in the Command Prompt.

## 2026-10-12  Pin to Taskbar, one network icon, Explorer layout
- **Pin to Taskbar**: right-click a program in the Start menu > Pin to Taskbar (or Unpin from Taskbar); or drag it from the Start menu onto the icons next to Start; or right-click a program file (.desktop) in Explorer > Pin to Taskbar. Right-click a taskbar icon to remove it.
- The second (Plasma's) network icon is now removed for good: the panel layout is fixed at login before the desktop starts.
- **Explorer like Windows 7**: no menu bar (the ☰ button at the right of the address bar has the menus; Ctrl+M shows the menu bar), only the navigation pane on the left (no Folders, Information or Terminal panels: F7, F11, F4 bring them back), and no Recent / Search For / Tags sections. Your existing Explorer settings are replaced once (old files kept as .bak).

## 2026-10-12  Write opens PDF files
- **Write opens PDF files** as editable documents, like Word: text with its fonts, bold/italic, colours and links, headings, bullet lists, tables, pictures, page breaks, and the page numbers as Write's footer. Open them from Write (Office button > Open) or right-click a PDF > Edit in Write. Scanned PDFs come in as pictures. Save as .docx, or as PDF again.

## 2026-10-12  Mail, network settings, Map Network Drive
- **Mail**, e-mail and contacts in the Outlook 2007 style (Start menu, or `outlook` in Run): your own IMAP/SMTP account, Gmail (app password) and Outlook.com (Microsoft sign-in). Folders, unread counts, date groups, Reading Pane (pictures from the Internet only when you allow them), drag messages to folders, Contacts with Address Cards and vCard import/export.
- Messages are written in Write's editor (fonts, colours, lists, tables, pictures); Word attachments open in Write; Write's Office button > Send > E-mail attaches the open document. mailto: links open Mail.
- Network icon in the taskbar: shows your IP address, gateway and DNS, with links to Network Connections and IP settings (Windows-style IPv4 dialog: DHCP or fixed address).
- **Map Network Drive** (Computer > Map network drive): \\server\share becomes a drive letter folder that every program can use, reconnected at sign-in (avoids Dolphin crashing on some SMB servers).
- GTK programs' drop-down lists open as a Windows-style list under the box.
