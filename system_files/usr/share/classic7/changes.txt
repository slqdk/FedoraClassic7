# Classic 7 changes, newest first. Shown by Classic 7 Update (View update history) and in the
# "Classic 7 was updated" message after a restart. Format: "## YYYY-MM-DD  Title", then "- item".

## 2026-10-12  Pin to Taskbar, one network icon, Explorer layout
- **Pin to Taskbar**: right-click a program in the Start menu > Pin to Taskbar (or Unpin from Taskbar); or drag it from the Start menu onto the icons next to Start; or right-click a program file (.desktop) in Explorer > Pin to Taskbar. Right-click a taskbar icon to remove it.
- The second (Plasma's) network icon is now removed for good: the panel layout is fixed at login before the desktop starts.
- **Explorer like Windows 7**: no menu bar (the ☰ button at the right of the address bar has the menus; Ctrl+M shows the menu bar), only the navigation pane on the left (no Folders, Information or Terminal panels: F7, F11, F4 bring them back), and no Recent / Search For / Tags sections. Your existing Explorer settings are replaced once (old files kept as .bak).

## 2026-10-12  Write opens PDF files
- **Write opens PDF files** as editable documents, like Word: text with its fonts, bold/italic, colours and links, headings, bullet lists, tables, pictures, page breaks, and the page numbers as Write's footer. Open them from Write (Office button > Open) or right-click a PDF > Edit in Write. Scanned PDFs come in as pictures. Save as .docx, or as PDF again.

## 2026-10-12  Network icon fixes
- Network icon: the Status and IP Settings... buttons work, and the popup shows the IP address, gateway and DNS of the connection.
- Only one network icon in the taskbar: Plasma's own one is removed, also on accounts that showed both.

## 2026-10-12  Mail, network settings, Map Network Drive
- **Mail**, e-mail and contacts in the Outlook 2007 style (Start menu, or `outlook` in Run): your own IMAP/SMTP account, Gmail (app password) and Outlook.com (Microsoft sign-in). Folders, unread counts, date groups, Reading Pane (pictures from the Internet only when you allow them), drag messages to folders, Contacts with Address Cards and vCard import/export.
- Messages are written in Write's editor (fonts, colours, lists, tables, pictures); Word attachments open in Write; Write's Office button > Send > E-mail attaches the open document. mailto: links open Mail.
- Network icon in the taskbar: shows your IP address, gateway and DNS, with links to Network Connections and IP settings (Windows-style IPv4 dialog: DHCP or fixed address).
- **Map Network Drive** (Computer > Map network drive): \\server\share becomes a drive letter folder that every program can use, reconnected at sign-in (avoids Dolphin crashing on some SMB servers).
- GTK programs' drop-down lists open as a Windows-style list under the box.

## 2026-10-12  Desktop colour fix, login keyboard
- The login screen gets the keyboard layout through its own keyboard file too (as System Settings > Login Screen > "Apply Plasma Settings" does), written at boot and whenever the system layout changes.
- The desktop no longer turns black after Appearance > Apply or an update (the colour was handed to Plasma in a format it can't read while the desktop is running).

## 2026-10-12  Clean-up, Breeze icons, no splash, no auto-lock, Danish keyboard at login, nicer Ribbon
- The screen no longer locks by itself after a few idle minutes or after sleep; Win+L still locks. (Can be turned back on in System Settings > Screen Locking.)
- The login screen uses the same keyboard layout as your desktop (e.g. Danish), checked at every login.
- The Dark Mode switch (Brightness & Color) no longer replaces Classic 7 with Breeze; if it already did, Classic 7 and your colour scheme come back.
- Appearance: fixed "Permission denied" on GTK theme files, which stopped Apply for every scheme except Classic 7 Standard.
- Breeze icons are now the standard (the Chicago95 icon set is gone); desktop icons are 32 px.
- No "Plasma made by KDE" splash at login.
- Square corners everywhere except Eleven Light: Plasma's text fields (Start menu search), list highlights and frames no longer borrow Breeze's rounded ones.
- Kate removed; KWrite is the Notepad.
- Clean-up: the other look-alike themes (Fedora, Valve, Air, Oxygen, Breeze Dark/Twilight) are removed; Konsole and Bazzite Updater are hidden from the menu (Command Prompt and Classic 7 Update replace them).
- Write: the Ribbon in the Office 2007 style (Blue, Silver or Classic, in the Office button menu) with the round Office button.

## 2026-10-12  Classic 7 Update, Classic login screen
- **Classic 7 Update** (Start > All Programs, or `classic7-update`): one click installs the newest Classic 7, app updates and new settings for your account, then offers a restart.
- After a restart into a new version, your account's settings (look, taskbar, Start menu, shortcuts) are brought up to date automatically at login.
- New login screen in the Classic style: the "Log On to Classic 7" dialog on the desktop blue.
- Appearance: OK now always applies the shown scheme; Apply never freezes the dialog and says what happened (log: `~/.cache/classic7/appearance.log`).

## 2026-10-12  Write
- **Write**, a word processor in the Word 2007 style: opens and saves .docx, .rtf and .doc, exports PDF. Pinned in the Start menu and opens Word files.

## 2026-10-12  Colour schemes
- New schemes in Appearance: XP Blue, Seven Basic and Eleven Light (rounded corners, flat title buttons).
- No more horizontal seam lines on the taskbar.
- Start menu: the recent programs list has no scroll bar and no duplicates.

## 2026-10-11  Start menu and Command Prompt
- Start menu in the Windows 7 layout with the Classic look: pinned and recent programs, All Programs, search, places on the right, Shut down button.
- Run dialog (Win+R) with Windows names such as cmd, control and notepad.
- Command Prompt: a terminal with an assistant using your own language model.
